3 CAS D’UTILISATION

Qui peut utiliser Commyweb ?

DESIGNERS

Faites commenter votre site par vos utilisateurs.

Pendant un test, demandez aux participants de signaler les textes qu’ils ne comprennent pas ou les boutons qu’ils ne trouvent pas, directement sur la page.

AGENCES WEB

Corrigez vos sites en équipe.

Designers, développeurs et chefs de projet commentent les pages à corriger. Échangez dans chaque discussion et marquez les corrections comme résolues.

CLIENTS ET RESPONSABLES DE SITE

Validez les corrections avant la mise en ligne.

Indiquez à votre prestataire les textes, images ou liens à modifier. Relisez la page après correction et marquez les points validés comme résolus.

Pour partager les commentaires, chaque participant doit installer l’extension et avoir accès au projet GitHub.

INSTALLATION

Comment utiliser Commyweb ?

Tout se configure dans la modale de l’extension. GitHub est nécessaire uniquement pour partager les commentaires.

  1. 1

    Installez l’extension

    Téléchargez Commyweb, décompressez l’archive et ajoutez le dossier à votre navigateur.

    Afficher les étapes d’installation

    Dans Chrome ou Brave, ouvrez chrome://extensions. Dans Edge, ouvrez edge://extensions. Activez Mode développeur, puis Charger l’extension non empaquetée. Sélectionnez le dossier décompressé.

  2. 2

    Épinglez votre retour

    Sur la page à relire, ouvrez Commyweb et renseignez votre nom. Cliquez sur Ajouter un commentaire, choisissez un endroit et écrivez.

  3. 3

    Invitez votre équipe

    Connectez votre projet GitHub dans les réglages de l’extension. Le bouton Inviter prépare un email avec le lien du projet. Vous envoyez cet email depuis votre messagerie.

Questions fréquentes.

Faut-il un compte GitHub pour utiliser Commyweb ?

Vous pouvez prendre des notes en mode local sans compte. Pour partager les discussions, chaque collaborateur a besoin d’un compte GitHub, d’un accès au dépôt choisi et de son propre jeton personnel. Les réglages de l’extension vous aident à créer ce jeton et à choisir le bon projet.

Où sont enregistrés les commentaires ?

En mode local, ils restent dans votre navigateur. En équipe, les discussions sont enregistrées dans les Issues du dépôt GitHub choisi : leur visibilité dépend des accès à ce dépôt. Votre jeton reste dans le stockage local de l’extension et n’est pas inclus dans les invitations.

Les commentaires de l’équipe se mettent-ils à jour automatiquement ?

Oui, Commyweb vérifie les mises à jour régulièrement, toutes les 15 secondes lorsque la page est active. La réception en temps réel nécessite un relais supplémentaire configuré par le responsable du projet ; ce relais n’est pas fourni avec ce site.

Sur quels navigateurs peut-on l’utiliser ?

L’extension s’installe sur Chrome, Edge et Brave sur ordinateur. Elle ne fonctionne pas sur les pages internes du navigateur ni sur les pages qui bloquent les extensions. Sur mobile, vous pouvez consulter ce guide ; l’extension nécessite un ordinateur.
