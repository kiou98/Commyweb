Comment ça fonctionne en 3 étapes.

Le responsable configure le projet et invite l’équipe. Chaque collaborateur peut ensuite commenter la page.

Choisir mon guide d’installation

Vous gérez le projet ? Suivez le guide Admin. Vous avez reçu une invitation ? Suivez le guide Utilisateur. Chaque guide explique le téléchargement, le dossier à choisir et la première utilisation.

    Ouvrez les réglages de l’extension. Choisissez le dépôt GitHub, créez votre jeton personnel, puis cliquez sur Vérifier et connecter. Le projet se configure ici, dans la modale.

Questions fréquentes.

Faut-il un compte GitHub pour utiliser Commyweb ?

Vous pouvez prendre des notes en mode local sans compte. Pour partager les discussions, seul le responsable configure un compte et un projet GitHub dans l’extension Admin. Les collaborateurs installent l’extension Utilisateur et ouvrent leur lien magique, sans compte GitHub ni jeton à renseigner.

Où sont enregistrés les commentaires ?

L’enregistrement sur votre appareil est immédiat. En équipe, Commyweb synchronise ensuite les discussions avec les Issues du projet GitHub. Le service Netlify garde le jeton du responsable pour connecter les collaborateurs ; leurs liens ne contiennent jamais ce jeton. Les liens personnels expirent après 30 jours et l’admin peut retirer un accès.

Les commentaires de l’équipe se mettent-ils à jour automatiquement ?

Oui, Commyweb vérifie les mises à jour régulièrement, toutes les 15 secondes lorsque la page est active. La réception en temps réel nécessite un relais supplémentaire configuré par le responsable du projet ; ce relais n’est pas fourni avec ce site.

Sur quels navigateurs peut-on l’utiliser ?

L’extension s’installe sur Chrome, Edge et Brave sur ordinateur. Elle ne fonctionne pas sur les pages internes du navigateur ni sur les pages qui bloquent les extensions. Sur mobile, vous pouvez consulter ce guide ; l’extension nécessite un ordinateur.
