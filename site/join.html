Lecture de votre invitation…
1

Installer Commyweb

Si vous l’avez déjà, passez à l’étape 2. Sinon, téléchargez l’extension et décompressez le dossier.

Télécharger l’extension
Comment l’ajouter à mon navigateur ?

Ouvrez chrome://extensions, activez Mode développeur, puis Charger l’extension non empaquetée. Sélectionnez le dossier décompressé.

2

Créer votre accès GitHub

Créer mon jeton GitHub ↗

Choisissez « Only select repositories », puis le projet indiqué. Les permissions Issues sont préremplies. Conservez le jeton pour le coller dans les réglages de l’extension, à l’étape suivante.

Vous devez avoir accès au projet sur GitHub. Sinon, demandez au responsable de vous y inviter. Ne collez aucun jeton sur cette page.

Ouvrir le projet GitHub ↗
3

Ouvrir la page et commenter

Le lien ci-dessous sélectionne le projet dans l’extension. Ouvrez Commyweb, collez votre jeton dans les réglages et cliquez sur Vérifier et connecter. Votre nom et votre premier commentaire suffisent ensuite.
