BIENVENUE DANS L’ÉQUIPE

Votre équipe vous attend.

Ouvrez la page à commenter, puis configurez votre accès dans la modale de l’extension.

Lecture de votre invitation…
1

Installer Commyweb

Si vous l’avez déjà, passez à l’étape 2. Sinon, téléchargez l’extension et décompressez le dossier.

Télécharger l’extension
Comment l’ajouter au navigateur ?

Ouvrez chrome://extensions (Chrome ou Brave) ou edge://extensions (Edge), activez Mode développeur, puis Charger l’extension non empaquetée. Sélectionnez le dossier décompressé.

2

Ouvrir la page à commenter

Le lien sélectionne le projet dans Commyweb. Les réglages se font ensuite dans l’extension.

Ouvrir la page à commenter →

3

Connecter l’extension

Ouvrez les réglages Commyweb. Utilisez Créer mon jeton GitHub, puis revenez sur la page et rouvrez Commyweb pour coller le jeton. Cliquez sur Vérifier et connecter.

Votre compte GitHub doit avoir accès au projet. Chaque collaborateur utilise son propre jeton. Celui-ci se saisit uniquement dans l’extension.
