Installer Commyweb Admin

Vous êtes responsable du site ou du projet ? Ce guide vous accompagne de l’installation à la première invitation.

Avant de commencer
  • Un ordinateur avec Chrome, Edge ou Brave.
  • Un compte GitHub et un dépôt sur lequel vous pouvez gérer les Issues.
  • Une seule version de Commyweb installée dans ce navigateur.

Pas le bon rôle ? J’ai reçu une invitation : suivre le guide Utilisateur.

Commencer l’installation →

  1. Téléchargez Commyweb Admin

    Cliquez sur le bouton ci-dessous. Le fichier se termine par .zip : c’est un dossier compressé.

    Télécharger la version Admin

    À vérifier : le fichier commyweb-admin.zip apparaît dans vos téléchargements.

  2. Décompressez le fichier ZIP

    Ouvrez votre dossier Téléchargements. Sous Windows, faites un clic droit sur le ZIP, puis Extraire tout et Extraire. Sur Mac, double-cliquez sur le ZIP.

    Déplacez le dossier obtenu vers un emplacement que vous conserverez, par exemple Documents / Commyweb Admin.

    À vérifier : ouvrez ce dossier. Il doit contenir un fichier nommé manifest.json. Ne sélectionnez pas le ZIP à l’étape suivante et ne supprimez pas ce dossier après l’installation.

  3. Ouvrez la page des extensions

    Choisissez votre navigateur. Copiez l’adresse correspondante dans sa barre d’adresse, en haut de la fenêtre, puis appuyez sur Entrée.

    Chrome
    chrome://extensions
    Edge
    edge://extensions
    Brave
    brave://extensions

    Activez Mode développeur sur cette page. Ce réglage permet d’installer le dossier téléchargé.

  4. Chargez le dossier décompressé

    Cliquez sur Charger l’extension non empaquetée (le libellé peut aussi être « Charger l’extension décompressée »). Sélectionnez le dossier contenant manifest.json, puis validez.

    À vérifier : une carte Commyweb apparaît dans la page des extensions et son interrupteur est activé.

    Un message indique que le fichier manifeste est introuvable ?

    Vous avez probablement choisi le ZIP ou un dossier parent. Ouvrez le dossier décompressé, repérez manifest.json, puis sélectionnez précisément le dossier qui contient ce fichier.

  5. Retrouvez Commyweb dans votre navigateur

    Ouvrez le site à commenter dans un onglet normal, puis actualisez la page. Cliquez sur le bouton Extensions (souvent une pièce de puzzle), à côté de la barre d’adresse, puis sur Commyweb.

    Épinglez Commyweb pour garder son icône visible : utilisez la punaise dans Chrome ou Brave, ou l’option d’affichage dans la barre d’outils dans Edge.

    L’installation est terminée. Continuez ci-dessous pour connecter votre projet.

  6. Préparez un projet GitHub privé

    Le projet GitHub sert à partager les discussions. Seul le responsable a besoin d’un compte GitHub.

    1. Connectez-vous à GitHub et créez un dépôt dédié au site, ou utilisez un dépôt existant.
    2. Choisissez Private pour un nouveau dépôt.
    3. Dans ses réglages, vérifiez que la fonctionnalité Issues est activée.
    4. Copiez l’adresse du dépôt : elle ressemble à https://github.com/votre-equipe/votre-projet.

    Gardez cette adresse pour l’étape suivante.

  7. Connectez Commyweb au projet

    1. Revenez sur le site à commenter, ouvrez Commyweb, puis ses réglages (roue dentée).
    2. Collez l’adresse du projet GitHub.
    3. Cliquez sur Garder la configuration ouverte pour conserver le panneau pendant votre passage sur GitHub.
    4. Cliquez sur Créer mon jeton GitHub. Le propriétaire et la permission Issues : Read and write sont préremplis.
    5. Dans GitHub, choisissez Only select repositories, puis sélectionnez uniquement le dépôt de votre projet. Choisissez une date d’expiration adaptée à la durée du projet et générez le jeton.
    6. Copiez le jeton, revenez dans Commyweb et collez-le dans le champ prévu.
    7. Cliquez sur Vérifier et connecter.

    Attendez la confirmation de connexion. Si elle échoue, vérifiez le dépôt sélectionné, l’expiration du jeton et la permission Issues en lecture et écriture.

    Le jeton reste réservé à l’Admin. Pour vos collaborateurs, utilisez les invitations de l’étape suivante.

  8. Invitez votre premier collaborateur

    1. Dans Commyweb, cliquez sur Inviter un collaborateur (personne avec un signe +).
    2. Saisissez son adresse email.
    3. Cliquez sur Préparer l’email d’invitation.
    4. Votre messagerie ouvre un brouillon. Vérifiez le destinataire, puis cliquez sur Envoyer dans votre messagerie.

    L’email n’est pas envoyé automatiquement. Si votre messagerie ne s’ouvre pas, utilisez Copier l’email complet et collez-le dans un nouveau message.

    Le collaborateur reçoit le téléchargement Utilisateur et son lien personnel. Vous pouvez aussi lui transmettre le guide d’installation Utilisateur.

  9. Vérifiez ensemble le premier échange

    Renseignez votre nom, cliquez sur Ajouter un commentaire, puis sur un élément de la page. Écrivez votre message et envoyez-le.

    Demandez à votre collaborateur de répondre. Retrouvez les réponses dans la même discussion, puis cliquez sur Résoudre lorsque la correction est validée.

    Vous êtes prêts : le retour et sa réponse sont réunis au même endroit.

UN BLOCAGE ?

On vous aide à continuer.

Je ne trouve pas Commyweb après l’installation

Revenez dans la page des extensions et vérifiez que Commyweb est activé. Actualisez le site à commenter, puis ouvrez le menu Extensions à côté de la barre d’adresse.

J’ai installé les deux versions

Gardez une seule édition par navigateur : Admin pour gérer le projet, Utilisateur si vous recevez une invitation. Désactivez l’autre dans la page des extensions, puis actualisez le site.

Je ne vois pas les commentaires de mon équipe

Vérifiez que vous êtes sur la même page web. Si Commyweb affiche « Local » ou « Sur cet appareil », vous n’êtes pas connecté au projet partagé. Un Utilisateur doit rouvrir son lien personnel ; un Admin doit vérifier la connexion dans les réglages. Utilisez aussi Actualiser dans la liste des discussions.

Je veux mettre Commyweb à jour

Téléchargez la nouvelle version de votre édition et décompressez-la. Remplacez les fichiers de votre dossier d’installation conservé, puis cliquez sur Actualiser sur la carte Commyweb dans la page des extensions. Actualisez ensuite le site à commenter.

Est-ce possible sur téléphone, Safari ou Firefox ?

Ce guide concerne Chrome, Edge et Brave sur ordinateur. Utilisez l’un de ces navigateurs pour installer Commyweb.

Toujours bloqué ? Contacter Néonéa en indiquant votre navigateur, l’étape et le message affiché.
