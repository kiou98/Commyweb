📘 Guide d'installation GitHub (Pas à pas) ▾
1 Créer votre dépôt de projet
Rendez-vous sur github.com/new ↗. Donnez-lui un nom (ex: commyweb-projet-a). Vous pouvez le mettre en Privé pour protéger vos retours.
2 Générer un Personal Access Token (PAT)
Allez sur Fine-grained tokens ↗ :
• Repository access : Choisissez votre dépôt.
• Repository permissions :
  🟢 Issues : choisir Read and write (Lecture et Écriture).
  (Metadata : Read-only est inclus automatiquement par GitHub).
• Cliquez sur Generate token et copiez le jeton github_pat_....
Alternative PAT Classic : cochez repo (si dépôt privé) ou public_repo.
3 Renseigner ci-dessous
Collez le token et indiquez votre dépôt sous la forme propriétaire/nom-du-repo.

1. Choisir le projet

Créez un dépôt privé pour conserver les commentaires de votre équipe.

Créer un dépôt sur GitHub ↗

2. Autoriser la synchronisation
