Connecter votre équipe

Partagez les commentaires de ce site avec votre équipe.

Vos saisies sont conservées sur cet appareil. Vous pouvez aller sur GitHub puis revenir ici.

1 Choisir le projet

Un dépôt GitHub conserve les commentaires de votre équipe. Créez-en un ou utilisez un dépôt existant avec les Issues activées.

Créer un dépôt ↗Retrouver mon projet ↗

2 Autoriser Commyweb

Le token est une clé d'accès qui permet à Commyweb de lire et publier les commentaires dans ce dépôt.

Créer mon token sur GitHub ↗

Choisissez « Only select repositories », sélectionnez votre dépôt, puis cliquez sur « Generate token ». Copiez le token et revenez ici.

Conservé sur cet appareil. Transmis au service d'invitation lorsque vous invitez un collaborateur.

Je ne retrouve pas mon dépôt

Collez d'abord votre token, puis chargez les dépôts auxquels il donne accès.

3 Connecter l'équipe

Vérifiez la connexion, puis utilisez « Inviter » en haut pour partager un accès personnel avec vos collaborateurs.

Options avancées · synchronisation

Renseignez l'adresse du relais une fois. Elle sera incluse dans les invitations ; les collaborateurs n'auront rien à configurer ici.

Sans relais, actualisation de secours toutes les 15 secondes.

Guide d'installation administrateur ↗

Inviter un collaborateur par email

Copiez l’email mis en forme, puis collez-le dans votre messagerie.

Le collaborateur installe l’extension Utilisateur puis ouvre son lien magique. Aucun compte GitHub ni jeton à saisir.

Préparez l’invitation pour la relire, ou copiez directement l’email HTML. Collez-le dans un nouveau message avec la mise en forme conservée. Ajoutez le destinataire et reprenez l’objet indiqué. Aucun email ne part automatiquement.

Voir le message avant de l’envoyer

Invitations en cours

Liens personnels valables 30 jours. Vous pouvez retirer un accès ici.

J’ai reçu une invitation

1. Ouvrez le lien personnel reçu par email, ou collez-le ci-dessous. Aucun compte GitHub ni token nécessaire.

2. Renseignez votre nom, puis ajoutez votre premier commentaire sur la page.
